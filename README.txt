CAMBER PRO — iPhone prototype
Extract the ZIP. For a PC layout preview, open Command Prompt in the extracted folder and run python -m http.server 8000 then visit http://localhost:8000. This is not sufficient for iPhone motion access: deploy the folder to an HTTPS static host (e.g. GitHub Pages). Open the HTTPS address in iPhone Safari, Share > Add to Home Screen. Enable sensors. Test in Safari first, then in standalone mode. Calibrate on a verified vertical surface. Confirm sign and magnitude with known angles before use. Sensor convention and accuracy have not been tested on physical hardware. Records are stored locally and may be cleared by iOS. Offline caching is included but not device tested.
